Project 3: Databases

Category: Databases

My artifact for Category Three: Databases is my CS 340 Grazioso Salvare Animal Rescue Dashboard, created during the CS 340 course. This project is a Python-based web application that connects to a MongoDB database to display, filter, and analyze animal rescue data. It includes components such as CSV data import, CRUD operations using PyMongo, and interactive visualizations built with Dash, including tables, charts, and maps that update in real time based on database queries.

I selected this artifact because it clearly demonstrates my ability to work with databases, build data-driven applications, and manage complex datasets in a real-world context. The integration of MongoDB with Dash showcases my skills in CRUD operations, data filtering, optimization, and user-centered interface design. Through my enhancement, I improved performance and scalability by adding MongoDB indexes, implementing aggregation pipelines, and designing more flexible multi-filter queries. These upgrades reflect my ability to improve existing systems with industry-standard techniques and deliver fast, accurate, and scalable data solutions.

Yes, this enhancement allowed me to meet the course outcomes I planned in Module One, particularly those related to designing, querying, and improving database systems. By implementing indexes, optimizing queries, and enhancing the dashboard’s real-time responsiveness, I strengthened my ability to apply data management principles in practical scenarios. At this point, I do not need to update my outcome-coverage plans because the enhancements I made fully support the original goals of improving database performance, scalability, and user experience.

Throughout the enhancement process, I learned how to apply advanced MongoDB features—such as indexing strategies and aggregation pipelines—to significantly speed up data retrieval and analysis. I also gained experience balancing performance with design trade-offs, making decisions that improved responsiveness without adding unnecessary complexity. One challenge I faced was optimizing multi-filter searches while keeping the dashboard fast, but by structuring queries carefully and choosing the right indexes, I resolved these issues and built a more efficient and scalable system.
